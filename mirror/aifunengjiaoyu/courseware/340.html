常考点

  • 体积不变：p / T = C（常数），即 p1/T1 = p2/T2
  • p 与 T（K） 成正比，p—T 图像是过原点的倾斜直线
  • 代入公式必须用 热力学温度 K，t(°C) + 273.15 = T(K)
  • p—t 图像延长线交横轴于 -273.15 °C（绝对零度）

易错点

  • 不能直接用 °C 代入 p/T = C 公式计算
  • p 与 t (°C) 不是正比关系，p—t 图像并不过原点
  • 查理定律的条件是质量 + 体积不变（等容变化）
  • 查理定律对应等容变化，不混淆盖·吕萨克定律（等压）
