# 乐启享课件库（合并后的站点）

这个目录是乐启享课件库的成品：站点外壳、目录数据、课件正文与素材。

## 哪些是本项目自己写的

站点外壳是乐启享机器人（[codebn.cn](https://codebn.cn/)）自己写的，
没有搬运别人的前端：

- 首页、目录页、学科与学段筛选、章节目录树、排序与搜索；
- 课件详情页与在线预览播放器（含本地课堂宿主与离线打包）；
- 下载打包与本地服务（`server/server.mjs`，只用 Node 自带模块）；
- 目录数据的清洗：去掉付费、试看、购买与退款的痕迹，把别处的名字换成
  乐启享的名字，把第三方角标与统计脚本摘掉；
- 逐门体检与质量分级（`tools/` 下的验收脚本，结论记在
  `quality-decisions.json`）。

## 哪些是收录来的

课件正文、封面、贴图、视频与声音来自公开发布的教学课件与开放许可的
开源课堂。本项目做的是**整理、本地化与再创作**。

每一份素材的来源、许可与署名，逐条写在它所属的来源目录下的 `NOTICE.md`
里；目录数据的 `author` / `license` / `sourceUrl` 字段记着同样的信息。
这些说明请一并保留。
