高一必修第一册 · 力的合成与分解实验

矢量运算 — 平行四边形定则与正交分解

场景模式
5.0 N ∠30°
F₁ (红)
4.0 N ∠120°
F₂ (蓝)
6.4 N ∠72°
合力 R (紫)
90°
F₁与F₂夹角
R = √(F₁² + F₂² + 2F₁F₂cosθ)
R = √(5.0² + 4.0² + 2×5.0×4.0×cos90°)
R = 6.40 N

📘 考点卡片

  • 平行四边形定则：合力是以两分力为邻边的平行四边形的对角线
  • 正交分解：Fx=Fcosθ, Fy=Fsinθ（θ为与x轴夹角）
  • 斜面分解：G·sinθ沿斜面向下，G·cosθ垂直斜面向下
  • 等效替代：合力与分力是等效替代关系，不是同时作用的实际力

⚠️ 易错陷阱

  • "合力是真实存在的第三个力" → 错误！是等效替代，不是外加力
  • sin/cos选反 → 关键是确认角度是相对于哪个轴
  • 分解方向随意选 → 必须按实际需要选择正交方向
  • "斜面上G分为mg/tanθ和mg·sinθ" → 公式混乱！

📝 随堂检测

1. 两个力F₁=3N, F₂=4N，夹角θ=90°，合力大小为？

R=√(3²+4²)=5N（勾股定理）。只有同向时才是3+4=7N，反向时是1N。

2. 一个10N的力与x轴成60°角，沿x轴的分力为？

Fx = Fcos60° = 10×0.5 = 5N。Fy = Fsin60° = 10×0.866 = 8.66N。注意哪个是cos哪个是sin！

3. 质量m=2kg的物体放在倾角θ=30°的斜面上静止。重力沿斜面方向的分力为？(g=10m/s²)

G∥ = mg·sin30° = 20×0.5 = 10N。G⊥ = mg·cos30° = 20×0.866 = 17.3N。沿斜面分力用sin不是cos！

4. 关于合力和分力，以下说法正确的是？

合力与分力是等效替代关系——实际受力分析时用分力就不用合力，用合力就不用分力。

5. 力F=10N，沿x轴分力Fx=8N，沿y轴分力Fy=6N。该力与x轴夹角的正切值为？

tanθ = Fy/Fx = 6/8 = 3/4 = 0.75, θ≈36.9°。tanθ=对边/邻边=Fy/Fx。
