参数影响总结

  • λ 增大（红光 vs 紫光）：Δy 增大，条纹变稀疏
  • d 增大（缝间距变宽）：Δy 减小，条纹变密集
  • L 增大（屏幕远离）：Δy 增大，条纹变稀疏
  • 白光入射时，中央明纹为白色，两侧出现彩色光谱（内紫外红）

生活与科技应用

  • 测量光波波长：通过测 Δy、d、L 反推 λ，历史上首次测定可见光波长
  • 光学薄膜测厚：利用干涉条纹判断薄膜厚度均匀性
  • CD/DVD 光盘彩色条纹：光盘刻槽相当于反射式衍射光栅
  • 干涉滤光片：利用多层薄膜干涉实现特定波长透射

随堂检测

1. 双缝干涉实验中，相邻明纹间距 Δy 与波长 λ 的关系是？
2. 保持 d 和 L 不变，用红光（~700nm）代替紫光（~400nm），条纹间距将？
3. 增大双缝间距 d，则相邻条纹间距 Δy 将？

公式推导：Δy = λL / d

1 两列波到达屏上P点的光程差：
δ = r₂ - r₁ ≈ d sinθ（θ 为P点偏离中央的角位置）
2 干涉加强条件（明纹）：
d sinθ = kλ   （k = 0, ±1, ±2, ...）
k = 0 为中央明纹，k = 1 为第一级明纹，以此类推
3 小角度近似（L ≫ d 且观察范围不大时）：
sinθ ≈ tanθ = y / L
代入得：d · y / L = kλ
4 解出第 k 级明纹位置：
y҃ = kλL / d
5 相邻明纹间距：
Δy = y҃₊₁ - y҃ = (k+1)λL/d - kλL/d = λL / d
✔ 条纹间距与波长成正比、与屏距成正比、与缝距成反比
