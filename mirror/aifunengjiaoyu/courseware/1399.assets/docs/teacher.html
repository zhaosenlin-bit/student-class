TEACHER'S GUIDE · OFFLINE EDITION

Fun Clubs · 校园社团招新

人教版新编七年级上册 Unit 5 同主题原创学习包。沿用 Campus Quest 的动漫校园与 Lin，串联广告阅读、主动咨询、社团选择和报名邮件。三个社团名称、广告、见面时间和人物对话均为原创教学情境，不是教材原文或真实学校招生信息。

本课学生应完成什么

  • 读懂社团广告，提取活动与参加条件，并指出文本依据。
  • 用英语主动询问时间、携带物品和参加条件，听取关键信息。
  • 用 can / can't 说明能力，理解“还不会但愿意学习”也是合理选择。
  • 比较兴趣、活动和时间，说明加入某一社团的理由。
  • 写出有称呼、自我介绍、能力与理由、相关问题和结束语的报名邮件。

建议一课时路线（约40分钟，可拆分）

环节时间参考组织与证据
进入招新日3分钟用英文昵称和可参加时间建立任务；大屏模式用虚构学生角色。
读广告8分钟至少完成两个社团。学生先独立读，再点击证据句；答案和证据都核对。
主动问 Lin10分钟至少完成所选社团的时间/携带物品提问、参加条件提问、能力回答和听力记录。支持键入和本地录音识别。
比较选择5分钟判断时间冲突，以 because 说明理由；没有唯一正确社团。
写邮件并修改11分钟先写再查遗漏，保留草稿。建议5—7句，根据学生能力调整。
迁移出口3分钟给 Jamie 推荐社团并说明依据；脱离提示向同桌介绍自己的选择。

使用方法

Windows 解压全部文件，双击 Start.cmd。Mac 解压后双击 Start-Mac.command，运行时保持终端窗口开启。浏览器访问本机地址即可，课堂学习不需要互联网。不要直接双击 index.html，因为录音、语音模型和视频范围读取需要本地服务。

拖动画面或按方向键环视，点击 Lin 切到对话。右侧始终是平面阅读与编辑区，避免把长文本贴在全景中。小屏会变成上下布局。字幕默认关闭，可按需打开；使用字幕会记录为支架辅助，不当作独立听力结果。

场景使用5段复用的走近/待机视频及6段新生成的原生语音对话视频。图书馆以Lin自然等待开场，避免旧入场片段人物距离变化造成衔接跳变，采用固定机位、共享参考帧与短交叉淡化。180°指宽画幅交互投影，不是双目立体VR180拍摄。不同浏览器的视频解码与设备性能可能影响衔接。

支持的提问例子：When do you meet? / What time does the club meet? / What should I bring? / Can I join? / Can beginners join? 不要求逐字背诵。对话是有限意图分支，不能回答任意开放问题。其他问题交给同伴或教师继续回应。

反馈边界与分层

本地语音识别使用 Vosk，把录音转成可编辑文字；识别成功并不等于发音准确。学生可以回听自己的录音。教师可从可理解度、停顿、重音和交流意图提供反馈。本课不输出伪精确的发音总分。

邮件检查仅识别内容线索，不做完整语法或语义评分；学生可能使用规则未覆盖的合理表达，教师可以填写理由后确认提交。规则匹配成功也不保证内容完全恰当，提交前须通读并确认。初学者可打开字幕和句型提示；进阶学生关闭提示，用不同问题表达同一意图，并解释选社团的依据。

个人设备：独立完成，导出学习档案和邮件。两人一组：轮换提问者与信息记录者。全班大屏：每轮由不同小组提问，其余同学先在纸上独立记信息，教师抽查；不能以一名学生操作完成代替全班掌握。

离线、隐私与复用

进度、文字和草稿保存在此浏览器的本机存储；应用不调用外部AI接口。录音仅用于当次识别与回听，可主动下载；刷新或换场景后不会保存音频。JSON档案不含录音。共用设备可通过“学习档案→重新开始”清除本机记录。模拟邮件不会发送；.example 地址是教学占位地址。

Windows 本机浏览器检查与ZIP文件校验不能替代Mac实机、麦克风与班级试教验收。Mac首次打开时若系统阻止未签名脚本，请核实来源后按学校设备管理要求操作；不要全局关闭系统安全设置。完整平台说明见课件根目录使用说明。
