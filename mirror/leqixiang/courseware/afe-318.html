课堂练习

应用题一

水下有一处点光源，距水面深度 d = 2.0 m，水的折射率 n = 1.33。试求：

  1. 水-空气界面的全反射临界角 C；
  2. 水面透光圆斑的半径 r；
  3. 水面透光区域的面积 A。
解：
(1) C = arcsin(1/n) = arcsin(1/1.33) = arcsin(0.7519) ≈ 48.75°
(2) r = d / √(n² - 1) = 2.0 / √(1.33² - 1) = 2.0 / 0.8769 ≈ 2.28 m
(3) A = πr² = π × (2.28)² ≈ 16.34 m²

应用题二

若上题的光源改为水平放置的直线光源，长度 L = 0.40 m，其他条件不变。求水面透光区域的面积，并与点光源情况比较。

解：
r = d/√(n²-1) = 2.28 m（同上）
透光区域为"体育场"形（stadium shape），宽 2r = 4.56 m，端部为半径 r 的半圆。
A = 2rL + πr² = 2×2.28×0.40 + 16.34 = 1.824 + 16.34 ≈ 18.16 m²
比点光源增加了 18.16 - 16.34 = 1.82 m²（增加约 11.1%）。

判断题

1. 对于水下点光源，水的折射率越大，水面透光圆斑的半径越大。

错误。n 越大，临界角 C 越小，透光半径 r = d/√(n²-1) 越小。例如 n=1.33 时 r≈1.14d，n=1.5 时 r≈0.89d。

2. 临界角的大小由介质折射率决定，与光源在水下的深度无关。

正确。临界角 C = arcsin(1/n) 仅由折射率决定，与光源深度无关。但透光区域的半径与深度成正比。

3. 对于水下点光源，透光圆斑的半径与光源深度成正比。

正确。r = d/√(n²-1)，当 n 固定时 r ∝ d。
错

4. 如果光源是水平放置的圆形发光盘，水面透光区域仍为圆形。

正确。圆形光源每个点产生半径 r 的透光圆斑，整体包络仍为圆形（半径 = 光源半径 + r），这是Minkowski和的性质。
