轮廓来源
ArcGIS公开图层「3b. Qing Dynasty (1820 AD)」，发布者cooper.storymaps。原始史料与许可未注明，仅作本机研究，不作为可分发、已核准的清朝地图。西北边线、库页岛与海上岛礁需重点核查。当前不表示当代国界。
核心山形
直接复用长征2048×2003的RG高度图及EPSG:3857投影。原始美术高度经地理重采样后保留；边缘120公里投影宽度渐变融合。未把美术高度冒充真实海拔。
外围延展
Mapzen真实DEM，经核心重叠区的单调映射转为同一美术高度尺度。等高线另取原始DEM，每500米，仅为现代高程参照。全国DEM投影像素约4.9公里。
历史设色
赭石、灰绿与暖白用于山形；金色与砖红另作香港岛、台湾和所选澎湖设色试验。底部阶段不自动更改1820候选框架；其余年层疆界仍待制作。
资料筛查
GitHub historical-basemaps的1815清朝面缺蒙古等外围，本版未用。My3dtiles的1820示例仅挂接中研院地图影像，并非完整三维开源地图。本版未直接下载CHGIS；候选矢量的原始来源与许可仍须追溯。
