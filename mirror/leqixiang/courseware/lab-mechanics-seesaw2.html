Measure Beam Mass: Instructions and Physics

This interactive 3D physics simulation demonstrates how the mass of a uniform beam can be determined using a known object and the principle of rotational equilibrium.

1. Objective

Determine the unknown mass of a uniform beam by adjusting the position and mass of a known object and the position of the pivot until the beam is in rotational equilibrium.

2. How to Use the Simulation

  1. Adjust the Object Position slider to move the red object along the beam.
  2. Adjust the Object Mass slider to change the known mass.
  3. Adjust the Pivot Position to move the support point.
  4. Use the +/− buttons for precise adjustment. Normal click: 0.01; Shift + click: 0.0001.
  5. Observe the beam rotation and net torque.
  6. Continue adjusting until the net torque is approximately zero.
  7. Record the object mass, object position, and pivot position.
  8. Calculate the unknown beam mass using the rotational equilibrium equation.

3. Torque and Sign Convention

Torque describes the turning effect of a force about a pivot.

τ = r × F

For this experiment:

  • Counterclockwise torque is positive (+).
  • Clockwise torque is negative (−).
  • The net torque is zero at rotational equilibrium.
Στ = 0

4. Determining the Unknown Beam Mass

Let xO represent the object position, xP the pivot position, and xB the beam's center of mass.

The uniform beam extends from −20 m to +20 m, so its center of mass is at xB = 0.

rO = xO − xP
rB = xB − xP

The gravitational torque of each mass is:

τO = −rOmOg
τB = −rBmBg

At equilibrium:

τO + τB = 0

Solving for the unknown beam mass:

mB = −mO (xO − xP) / (xB − xP)

Since xB = 0:

mB = mO (xO − xP) / xP

5. Suggested Experiment

  1. Set the object mass to 2.00 kg.
  2. Set the object position to −10.00 m.
  3. Move the pivot until net torque is zero.
  4. Record the balanced pivot position.
  5. Calculate the unknown beam mass.
  6. Repeat using different object masses.
  7. Compare your calculated results.

6. Important Physics Notes

  • The beam is assumed to be uniform.
  • Its center of mass is at the geometric center.
  • The unknown beam mass is included in torque calculations.
  • The pivot is assumed frictionless.
  • The pivot force produces zero torque about the pivot.
  • Nonzero net torque produces rotational acceleration.
  • Rotational equilibrium occurs when net torque is zero.
