高三｜ 人教版高中物理选择性必修第三册｜ 第五章 原子核｜ 放射性元素的衰变与三种射线
α射线 — 氦核 4He (正电)
β射线 — 电子 e⁻ (负电)
γ射线 — 电磁波 (不带电)

α 射线 — 氦核

本质氦原子核 4₂He
电荷+2e（带正电）
相对质量~4 u（质量最大）
速度~0.05c（较慢）
电离能力最强（≈10⁴ 对/cm）
穿透能力最弱（一张纸可挡住）
磁场中偏转偏转方向与β相反，半径较大

β 射线 — 电子

本质高速电子流 e⁻
电荷-e（带负电）
相对质量~1/1836 u（质量最小）
速度~0.9c（接近光速）
电离能力中等（≈10² 对/cm）
穿透能力中等（几毫米铝板可挡住）
磁场中偏转偏转方向与α相反，半径最小

γ 射线 — 光子

本质高频电磁波（光子）
电荷0（不带电）
相对质量0（静止质量为零）
速度c（光速 3×10⁸ m/s）
电离能力最弱（≈1 对/cm）
穿透能力最强（需厚铅板或混凝土）
磁场中偏转不偏转（不受洛伦兹力）

常考点梳理

  • α 带正电、质量大 → 电离能力强 → 穿透本领弱
  • β 带负电、质量小 → 偏转半径最小、轨迹最弯
  • γ 不带电 → 在磁场中不偏转、穿透本领最强
  • 洛伦兹力 F=qv×B → 由左手定则判断偏转方向
  • 偏转半径 r=mv/(qB) → m 越小半径越小（β 偏转最明显）
  • α 与 β 偏转方向相反 → 电性相反导致洛伦兹力反向

易错点纠偏

  • γ 射线不带电 → 在磁场中不发生任何偏转
  • β 质量远小于 α → β 偏转半径最小（不是 α）
  • α 和 β 偏转方向相反 → 因带电符号相反
  • 穿透能力强 ≠ 电离能力强（二者此消彼长）
  • γ 穿透最强但电离最弱 → 勿混淆
  • 磁场反向时 α 和 β 偏转方向均反向
