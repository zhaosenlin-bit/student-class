乐启享 · 课件使用说明
=====================

怎么打开
--------
双击「启动课件.cmd」（Mac / Linux 双击「启动课件.sh」）。

它会在本机开一个很小的地址（127.0.0.1），并自动打开浏览器。
课件就显示在浏览器里，和在乐启享网站上看到的一样。
用完直接关掉那个黑色窗口就行。

为什么不能直接双击 HTML
-----------------------
这份课件的代码是按「模块」写的。浏览器不允许一个网页从硬盘上读取
另一个模块文件，所以直接双击 HTML 会看到一片空白。启动器做的就是
把这一小段课件用本机地址递给你，安全、离线、不联网上传。

离线使用
--------
课件需要的脚本、图片、字体、声音都在本文件夹里，全程不联网。
如果电脑装了 Node.js 或 Python，启动器用哪一个都行；
两个都没有时，启动器会直接打开 HTML，能看的部分照常看。
