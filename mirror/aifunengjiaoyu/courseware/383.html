📘 考点卡片

  • 临界条件：外力达到最大静摩擦力时（F = fmax = μsN），物体开始滑动
  • 摩擦力突变：滑动瞬间 f 从 fmax 突变为 fk = μkN，变小！
  • 滑动后：f = μkN = 常数，不再随 F 变化；a = (F - fk) / m
  • 临界时刻 a = 0：F = fmax 时物体即将滑动但 a 仍为 0

⚠️ 易错陷阱

  • "滑动后摩擦力仍等于拉力" → 错误！滑动后 f = μkN，不随 F 变
  • "刚滑动时 a = 0" → 注意！临界时刻 a=0，但一旦滑动 a 从 0 突变
  • "摩擦力连续变化" → 错误！从静到动摩擦有突变（跳变下降）
  • "临界力用 μk" → 错误！临界用 μs，滑动后才用 μk

📝 随堂检测

1. m=5kg, μs=0.4, μk=0.3, g=10m/s²。物体从静止被拉动，临界力为？

F_crit = μs·N = 0.4 × 5 × 10 = 20N。临界力用μs不是μk！N = mg = 50N。

2. 上述物体在拉力F=25N时（已滑动），摩擦力为？

滑动后摩擦力 = μk·N = 0.3×50 = 15N。注意：不是20N(μs)也不是25N(F)！

3. 上述物体拉力F=10N时（静止），摩擦力为？

静止时静摩擦力 = 外力 = 10N（自调节）。不是μsN（那是最大值，不是当前值）！

4. 在摩擦力突变的瞬间，摩擦力从 ____ 突变为 ____？

摩擦力从最大静摩擦f_max突变为滑动摩擦f_k。因为μs > μk，所以摩擦力突然变小！

5. 质量为4kg的物体，μs=0.5，μk=0.4，g=10m/s²。在临界时刻，物体加速度为？

临界时刻F=f_max=20N，合力=0，a=0。但一旦开始滑动，f突变为μkN=16N，a=(20-16)/4=1m/s²。
