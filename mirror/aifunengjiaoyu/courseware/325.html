核心公式
光程差
Δ = 2d + λ/2
2d：几何路程差；λ/2：半波损失附加光程
明纹条件（k = 1, 2, 3…）
2d + λ/2 = kλ  →  2d = (2k−1)·λ/2
两束反射光相位差为 2π 的整数倍，加强
暗纹条件（k = 0, 1, 2…）
2d + λ/2 = (2k+1)·λ/2  →  2d = kλ
k=0 时 d=0，接触处为暗纹（半波损失导致）
条纹间距
Δx = λ / (2θ)
θ↑ → Δx↓（条纹变密）；λ↑ → Δx↑（条纹变疏）
半波损失来源
空气(n≈1) → 玻璃(n≈1.5)
光从光疏→光密介质，在下玻璃板表面反射时发生半波损失

📝 课堂练习

1. 劈尖干涉中，相邻两条明纹（或暗纹）的间距公式为（ ）。
A. Δx = λ/θ B. Δx = λ/(2θ) C. Δx = 2λ/θ D. Δx = θ/λ
▼ 查看答案
答案：B
两相邻明（暗）纹对应的空气膜厚度差为 λ/2，设条纹间距为 Δx，劈尖角为 θ，则 tanθ ≈ θ = (λ/2) / Δx，故 Δx = λ/(2θ)。
2. 在劈尖干涉实验中，两玻璃板接触处观察到的条纹是（ ）。
A. 明纹 B. 暗纹 C. 半明半暗 D. 无法确定
▼ 查看答案
答案：B
接触处空气膜厚度 d = 0，两束反射光的光程差仅为 λ/2（由半波损失引起），满足暗纹条件。实验中也确实观察到接触处为暗纹，这证实了半波损失的存在。
3. 增大劈尖角 θ 时，条纹间距将____；改用波长更长的红光照射，条纹间距将____。
A. 增大 / 增大 B. 增大 / 减小 C. 减小 / 增大 D. 减小 / 减小
▼ 查看答案
答案：C
由 Δx = λ/(2θ) 可知：θ 增大，分母增大，Δx 减小（条纹变密）；λ 增大，分子增大，Δx 增大（条纹变疏）。可拖动上方滑块验证。
4. 半波损失发生在哪个界面？为什么上表面反射不发生半波损失？
▼ 查看答案
答案：半波损失发生在下玻璃板的上表面（空气→玻璃界面）。
原因：光从空气（光疏介质，n≈1）射向玻璃（光密介质，n≈1.5），在界面反射时相位突变 π（等效于附加 λ/2 的光程）。
而上表面反射发生在玻璃→空气（光密→光疏），无半波损失。
