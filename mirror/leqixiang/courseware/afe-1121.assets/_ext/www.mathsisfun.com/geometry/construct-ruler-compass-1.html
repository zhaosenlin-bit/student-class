Constructing a Triangle with 3 Known Sides

If we know the lengths of a triangle's 3 sides, we can draw the triangle using a ruler and drafting compass.

It is fun and easy to do.

In this example we are told the triangle has sides of 23, 17 and 12 (press the play button):

images/construct.js?mode=tri3sides

Note: this isn't a classic construction as we measured using a ruler, but it is still a perfectly good method.

The Steps:

  1. Draw the base: Mark a start point
  2. Base length: Set the compass to 23. Place compass on start point and draw an arc, mark the crossing point
  3. First arc: Set the compass to 17. Place compass on start point and draw an arc up high
  4. Second arc: Set the compass to 12. Place the compass at the other end and draw another arc that crosses the first arc, mark the point
  5. Finish: Use the ruler to draw straight lines between each point

Why arcs? An arc marks every single point that's the exact right distance from a corner. Where the two arcs cross is the only point that satisfies both side lengths at once

Will Any 3 Side Lengths Work?

Any side of a triangle must be shorter than the other two sides added together.
