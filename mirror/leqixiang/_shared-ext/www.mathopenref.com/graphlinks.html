Save GFE chart as a link

In a web page

Copy and paste the HTML code below into a web page. This will create a link that when clicked will bring up the chart as you have it currently set up. You can change the link text "GFE" to anything you wish.
To place it on clipboard, select the text, then press Control-C, or use the Edit, Copy menu.

In a Word document

Insert a link into the text using Word's 'insert - link' command. It will ask for link text which can be anything you choose, and an address to go to when the link is clicked. Copy and paste the address below for this. This will create a link that when clicked will bring up the chart as you have it currently set up.
To place it on clipboard, select the text, then press Control-C, or use the Edit, Copy menu.

Email

Copy the URL in the text box above and paste it into an email, ensuring there is white space before and after it. The recipient can then click on the link to see the chart as it is currently set up.

Manually

You can create the link and its parameters yourself, or have other software do it. For details on this see How to customize the General Function Explorer (GFE)
