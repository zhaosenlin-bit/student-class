Cut a Line Segment into N Equal Parts

How to cut a line segment into N equal parts using just a compass and a straightedge

Here we cut a line segment into 3 equal parts, but the same approach can be used to cut a line into any number of parts:

images/construct.js?mode=segment3

Steps:

  • Draw a line from the start point, heading somewhat upwards
  • Use the compass to divide it into 3 segments
  • Use the compass to create a parallel line heading backwards and down from the end point
  • Use the compass to divide it into 3 segments
  • Connect the intersection points of the two new lines, and where they cross the original line it will be neatly subdivided
Compass Tip: Any compass width will work, as long as it fits your page and you keep it the exact same width for every step
