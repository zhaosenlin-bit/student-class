# 互动课件（第一来源）

这一组课件取自一个公开课本站**游客可见**的免费课件，著作权属于各自的
作者与该站点的运营方。本目录只是离线镜像：正文、脚本、样式、图片原样
保存，用来在没有网络的时候继续上课。

## 乐启享在这一组课件上做的改动

- 目录、筛选、详情页、预览播放器、下载打包是乐启享自己写的
  （见 `tools/build-leqixiang.mjs` 与 `mirror/leqixiang/site`）。
- 站点外壳的品牌、配色、页脚全部换成乐启享（信息取自
  [codebn.cn](https://codebn.cn/)）；页面上原本的登录、反馈、购买、
  退款、投稿后台与经营后台整套商业机制全部卸掉，只留
  「看目录 → 在线预览 → 下载」这一条线。
- 课程正文里别人的品牌名、统计脚本、站外链接被清掉
  （见 `tools/brand-scrub.mjs` 与 `tools/brand-audit.mjs`）。
- 每门课逐门在真浏览器里打开体检，画面空白、控件失效或打不开的课
  从目录里剔掉（结论见 `mirror/leqixiang/quality-decisions.json`）。
- 依赖库、字体、贴图、模型全部改写成本地副本，课件可以完全离线打开，
  下载下来的压缩包在断网的机器上照样能用。

## 边界

本目录只包含公开可见的部分。线上放在付费墙后面的课程没有被抓取，
也没有绕过后门；目录里出现的每一门都是本地真能打开的。
