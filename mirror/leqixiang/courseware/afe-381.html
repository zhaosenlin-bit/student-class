📘 考点卡片

  • 静摩擦力随外力变化：0 ≤ f静 ≤ fmax，且 f静 = F（外力），自调节！
  • 滑动摩擦力：f = μN，与外力大小无关，只与μ和N有关
  • 最大静摩擦力 > 滑动摩擦力：fmax ≈ μsN > μkN = fk
  • 方向：与相对运动或相对运动趋势方向相反（不是运动方向！）

⚠️ 易错陷阱

  • "静摩擦力一定等于μN" → 错误！只有最大静摩擦才≈μsN，平时 f静=F
  • "摩擦力方向一定与运动方向相反" → 错误！是与相对运动方向相反
  • "物体静止时摩擦力一定为0" → 错误！静止时若有外力，f=F≠0
  • "滑动后 f = μsN" → 错误！滑动后用μk不是μs

📝 随堂检测

1. 质量m=5kg的物体放在水平面上，μs=0.4，μk=0.3，g=10m/s²。临界拉力（恰好拉动时的拉力）为？

F_crit = f_max = μs·N = 0.4×5×10 = 20N。临界时用μs不是μk！

2. 上述物体，当拉力F=10N时物体静止，此时摩擦力大小为？

物体静止时，静摩擦力 = 外力 = 10N。不是μsN=20N！静摩擦是自调节的。

3. 物体被拉动后，拉力仍为20N。此时物体所受摩擦力为？

滑动后摩擦力 = μk·N = 0.3×50 = 15N，不再等于拉力！所以有a=(20-15)/5=1m/s²。

4. 物体向右滑动时，摩擦力的方向是？

摩擦力方向与相对运动方向相反，物体向右滑动，摩擦力向左。

5. 质量为m的物体放在倾角θ的斜面上静止，斜面对物体的摩擦力大小为？

静止时摩擦力=重力沿斜面分力=mg·sinθ（不是μmg·cosθ！μmg·cosθ是最大静摩擦）。
