Color the shapes, make your own patterns.

Click on image for color and rotation. Shapes automatically snap to corners. Can select multiple using a selection rectangle.

Can you do these challenges?

  • The House Challenge: Can you build a house using only squares and triangles?
  • Fancy House Challenge: Now use any and all shapes to make the house fancy
  • Pattern Challenge: Create a repeating pattern of colors (like Red, Blue, Red, Blue)
  • Tiling: Now make a tiled repeating pattern (tesselation)
  • The Mirror Challenge: Try to make a design that looks exactly the same on the left and right sides (bilateral symmetry)

We are always looking for ways to make our tools better! If you have ideas for new shapes or features you would love to see, please let's know.
