### 第五个来源：54 门铜匠实验室 3D 互动课（中文 · 人教版对标）

前四个来源补进来的是"物理 / 化学的模拟实验"。真正缺的还有一类：
**一节课本身就是一次可操作的工业流程 / 实验探究** —— 有过程、有条件、
有考核，不是单个实验现象。找了一圈，中文、免费、许可清楚、还能整个
搬回本地的，只有
[sdvch/tongjiang-lab](https://github.com/sdvch/tongjiang-lab)（铜匠实验室，
CC BY-NC 4.0）。

54 门课件，每门一个 **1 MB 上下的单文件 HTML**，里面自带一份 three.js：

每一门都是真的课堂课件，不是示意图：3D 场景可以转、可以拖，参数能实时
调（温度、压强、催化剂开关都在面板上），左边是分步引导（为什么建厂 →
为什么净化 → 为什么加压 → …），右边是方程、条件与产率曲线，最后还有
"考核 · 当班长"。**对着人教版教材标到了具体章节**
（"选择性必修1 化学反应原理 · 第二章 …"）。

`tools\mirror-tongjiang.mjs` 做的事：

- 把 54 门课件和 54 张封面原样搬进 `mirror\tongjiang\`，课件内容一个字
  没改 —— 它们本来就是零外部依赖的单文件
- 目录按学科 / 学段整理好，封面用上游自己的截图（不是占位图）
- 归属写进 `mirror\tongjiang\NOTICE.md`

`tools\check-tongjiang-offline.mjs` 会逐门开一遍：确认 **WebGL 画布真的
画出了东西**（读像素，不是只看 `canvas` 标签在不在）、中文文案正常、
而且**没有一次外部请求**。54 / 54 全绿。
