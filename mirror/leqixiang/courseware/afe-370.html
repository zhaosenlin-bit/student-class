常考点与易错点

常考点

  • 最高点临界条件：单轨 v顶 ≥ √gR，否则脱轨
  • 单轨（轻绳类）：最高点向心力由重力+支持力共同提供
  • 双轨（管道类）：最高点速度最小可为 0
  • 支持力、压力方向判断——指向圆心为正，背离圆心为负
  • 最低点支持力最大：N = m(v²/R + g)

易错点

  • 不分单轨双轨，统一用 v=√gR 判定
  • 混淆最高点支持力方向（单轨指向圆心；双轨可能背离圆心）
  • 误认向心力是独立于重力、支持力之外的"第三种力"
  • 误判脱轨条件：单轨 N=0 即脱轨，双轨永不脱轨
  • 能量分析遗漏：v底² = v顶² + 4gR
核心公式推导

最高点受力分析

mg + N = mv顶² / R
单轨临界：令 N = 0 ⇒ mg = mv顶²/R ⇒ v顶,min = √gR
最低点对应初速度：v0,min² = v顶,min² + 4gR = 5gR ⇒ v0,min = √5gR
双轨最低点对应：v顶可为零 ⇒ v0,min² = 4gR ⇒ v0,min = 2√gR
能量守恒：½mv底² = ½mv² + mgR(1 − cosθ)，其中 θ 为偏离最低点角度
