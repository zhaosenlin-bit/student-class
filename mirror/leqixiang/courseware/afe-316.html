干涉公式与原理

空气薄膜厚度： d = r² / (2R)

光程差（反射光，含半波损失）： δ = 2nd + λ/2

暗环（反射光）： 2nd = kλ → rk² = kλR/n  (k = 0, 1, 2…)
明环（反射光）： 2nd = (k+½)λ → rk² = (k+½)λR/n

半波损失：光从光疏介质（空气 n≈1）射向光密介质（玻璃 n≈1.5）并在界面反射时，反射光发生 π 相位突变，等效附加 λ/2 光程差。
反射光中心为暗斑；透射光无半波损失，中心为亮斑。

观察与填空

1. 反射光牛顿环干涉图样中，中心为 斑，这是因为空气薄膜上下表面反射的两束光之间存在 的额外光程差（半波损失）。

2. 相邻暗环的间距随级次 k 的增大而 （填"增大"或"减小"），因为 rk ∝ √k，Δr 近似与 1/√k 成正比。

3. 在透射光中观察牛顿环，中心为 斑，明暗环纹位置与反射光 （填"相同"或"互补"）。
