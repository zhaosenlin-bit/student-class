# 微小世界 · 从放大镜到显微镜（六年级科学）

单文件离线课件，`micro-world-6.html` 直接双击就能用，不依赖网络、不需要服务器。

## 一键装进课件库

在这个文件夹里执行（把路径换成你自己的仓库目录）：

```
node install.mjs "D:\path\to\student-class"
```

装完启动：

```
node server/server.mjs
```

打开 http://localhost:4173/ ，在课件库搜索「微小世界」或筛选「小学 · 科学」就能看到卡片。

## 装了什么

| 文件 | 去处 | 作用 |

## 课堂结构

1. **放大镜下的世界**：四种标本可换（叶片、蝴蝶翅膀、食盐晶体、印刷小字），镜片可拖动、滚轮可调倍数。让学生自己发现“倍数上去，视野下来”。
2. **两级放大**：目镜 5/10/16× 与物镜 4/10/40× 自由组合，实时显示总倍数，旁边同步呈现视野里的细胞大小。
3. **显微镜与调焦**：点击六个部件看说明；拖动调焦滑块，把模糊的视野调成清晰的洋葱表皮细胞，并提示倒像的移动方向。
4. **细胞与微生物**：洋葱表皮细胞带标注；池塘水场景里草履虫在游，酵母菌、细菌和水中碎屑一起出现。
5. **闯关**：五道题，选完即时判分并给出讲解。
