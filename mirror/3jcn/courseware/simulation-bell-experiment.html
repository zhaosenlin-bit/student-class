BELL'S CHSH EXPERIMENT
Entangled photon pairs with quantum correlations
Classical local realism gives |S| ≤ 2, while quantum mechanics can reach 2√2 ≈ 2.828.
Controls:
This simulation sends entangled photon pairs from a source to two distant analyzers. The analyzer settings are a, a′, b, and b′. The program measures correlations and computes the CHSH quantity:
S = E(a,b) - E(a,b′) + E(a′,b) + E(a′,b′).

Quantum prediction for a singlet-like state:
E(θA, θB) = −cos[2(θA − θB)] for polarization form
or E(θA, θB) = −cos(θA − θB) in a spin-style simplified model.

This simulation uses the polarization-style CHSH form so the standard angle set 0°, 45°, 22.5°, 67.5° gives S ≈ 2.828.

Definitions

S = E(a,b) − E(a,b′) + E(a′,b) + E(a′,b′)
In a local hidden-variable model, |S| ≤ 2. In quantum mechanics, entangled states can violate that bound. This page is an educational visualization prepared for teaching.
