60 Degree Angle

How to construct a 60 Degree Angle
using just a compass and a straightedge

images/construct.js?mode=60degree

Steps to Follow

You can construct a 60° angle using only a straightedge and a compass:

  1. Start with a straight line segment
  2. Place the compass point where you want the angle and draw an arc that crosses the line and goes past where you think 60° is
  3. Without changing the compass width, place the compass point where the arc crosses the line and draw an arc that intersects the first arc
  4. Draw a straight line from the angle's starting point to that crossing point ... done!

Cool Bonus:

  • Want a 30° angle? Construct a 60° angle and then bisect it (or use the 30° degree angle method)
  • Want a 120° angle? Construct another 60° angle next to the first one
