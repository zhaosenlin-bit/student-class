How to Use the Elevator Physics Simulation

Use this simulation to investigate elevator motion, Newton's Second Law, normal force, apparent weight, velocity, and acceleration. A useful way to study the motion is to pause the elevator during each stage and compare the normal force N with the passenger's weight mg.

1. Set the Elevator Conditions

  1. Set the Passenger Mass.
  2. Set the Elevator Acceleration.
  3. Set the Maximum Speed.
  4. Click Start to begin the elevator motion.

2. Pause at Each Stage

Use the Pause button to stop the elevator temporarily during different stages of its motion.

Try to pause while the elevator is:

  • Accelerating upward
  • Moving upward at constant velocity
  • Slowing down near the top

At each stage, compare the live measurements for normal force, weight, velocity, and acceleration.

3. Compare Normal Force and Weight

N − mg = ma

Observe the relationship between the normal force exerted by the elevator floor and the passenger's weight.

  • When the elevator accelerates upward, N > mg.
  • When acceleration is zero, N = mg.
  • When acceleration is downward, N < mg.

Because the scale measures the normal force, the scale reading is the passenger's apparent weight.

4. Study the Motion Graphs

Click Show Graph to display the motion graph.

Switch among:

  • Position vs. Time
  • Velocity vs. Time
  • Acceleration vs. Time

Pause the simulation and compare the shape of each graph with the current elevator motion and the live numerical values.

What to Observe During One Elevator Trip

Elevator Stage Acceleration Normal Force vs. Weight Passenger Feels
At rest before starting a = 0 N = mg Normal weight
Accelerating upward Upward N > mg Heavier
Moving upward at constant speed a = 0 N = mg Normal weight
Moving upward but slowing down Downward N < mg Lighter
Stopped at the top a = 0 N = mg Normal weight
Suggested Investigation: Run the elevator several times using different passenger masses and different elevator accelerations. Use the Pause button during the accelerating and decelerating stages. Record the values of mg, N, and a. Then check whether your measurements satisfy:
